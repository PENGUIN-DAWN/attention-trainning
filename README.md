# 专注力小宇宙 · Attention Trainning

供自己和朋友使用的安卓离线注意训练工具，本版整合公共反馈与发布恢复保护。当前版本 **1.64 / versionCode 13**，Android 8.0+。包名 `cn.focusuniverse.offline`。

使用安卓原生外壳和系统 WebView，十六项训练、音频和页面全部内置。没有账号、广告、支付、服务器或联网权限。训练成绩不作为医学诊断或一般能力评分。

## 开发

项目背景、训练目录、历史决定、验证证据和待确认事项统一从[项目知识库](docs/knowledge-base/README.md)查阅；协作入口见 [AGENTS.md](AGENTS.md)。

先阅读 [构建说明](docs/BUILD.md)、[架构说明](docs/ARCHITECTURE.md)、[测试入口](docs/TESTING.md) 和 [数据与签名边界](docs/DATA-AND-SIGNING.md)。

```powershell
python -X utf8 android-app/dev.py doctor
python -X utf8 android-app/dev.py release --jobs 3
```

训练注册表：`android-app/config/trainings.json`；界面：`templates/`、`styles/`、`app/`；验证：`tests/`；工程脚本：`tooling/`。
版本仅从 AndroidManifest.xml 读取。构建支持 Windows 与可配置工具路径，未验证跨操作系统构建。
原签名不在仓库中；克隆源码不能凭空获得覆盖原安装包的签名能力。

本版验证结果见上方完整报告和运行凭据；旧基线不变，已审查的运动改动使用独立 1.61 / 1.62 / 1.63 运动契约和 1.64 反馈契约，其余题面、规则与音频继续回归。
浏览器软件帧间隔不等于安卓物理帧率；真机输入法、耳机、显示时序和覆盖安装尚需手机确认。

## 日常开发与恢复

默认一个写代码任务，每次从同步的 main 建立短期 codex/ 分支，经 PR 普通合并；提交源码后再生成发布凭据与产物。main 的软件验收与手机验收分别记录。具体见 CONTRIBUTING 和知识库 MAINTENANCE。

当前发布拒绝覆盖历史 APK/ZIP，暂存按工作区隔离，凭据绑定源提交、构建输入及工具版本。源码、签名和手机数据分别恢复；签名加密备份与真机覆盖升级尚待作者完成，见 DATA-AND-SIGNING 和知识库 EVIDENCE。
