## 怎样判断一条信息能否直接使用

- **用户确认**：用户在对话中明确表达的定位或决定，注明确认日期。
- **当前实现**：能够在现有源码或配置中定位；不能据此推定手机实测通过。
- **既有验证**：已经留存的报告结论，注明对应版本；本次是否重跑另外说明。
- **历史材料**：记录当时版本和背景，不能直接作为当前实施命令。
- **建议 / 待确认**：尚未成为用户决定、实现或验收结果，不当作已承诺的计划。

遇到冲突先看用户最新明确决定；实现事实回到源码和配置，验证事实回到对应版本报告。无法消解的冲突记入待确认，不补造结论。
