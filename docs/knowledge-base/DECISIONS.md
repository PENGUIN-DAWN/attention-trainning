## 2026-10-22 UI 决定

D08：作者提供浅蓝与奶油配色的界面稿，要求增加灵动动效、保留鼠标悬停，并将训练素材之外的应用图标改为 SVG。1.60 实施首页、训练外围、记录、弹窗和设置外观；保留训练规则、时序及数据。设计稿中的暂停继续和逐题弹窗没有覆盖现有规则。原生系统图形使用 VectorDrawable。见 [实现说明](../../android-app/UI改版开发说明-1.60.md)。

D06 中的深色外观是 1.50–1.51 历史状态，1.60 以 D08 为当前外观决定。

## 版本脉络

D11（2026-10-22）：作者要求建立统一可复用的音效与动效基础，普通界面和训练点击共用播放能力，各训练自行决定触发时机，装饰音效与题目音频分离，保留第七项已有效果与有效观察时长。当前工作区已抽出 `FocusFeedback`，先接入“界面设置”按钮和第七项有效作答点击，保留原入场/倒数/确认短音；增加可选装饰静音偏好，数字题目音频独立。本次不改训练条件、计分、规则版本或观察/运动时长，未发布新 APK。接入方法见 [统一音效与动效](../FEEDBACK.md)。

D10（2026-10-22）：作者要求十球档运动 10 秒，并用示范视频借鉴逐颗入场、短音、立体高光和目标发光；随后明确不改小球与背景颜色。1.62 最终保持原蓝球、棕金目标、浅色背景及方形场地，只增加呈现效果；规则 v3 保留 v1/v2 成绩兼容。十二球仍为 8 秒，速度沿用 1.61。见 [入场与立体效果](../MOTION-162.md)。

D09（2026-10-22）：作者反馈动态训练卡顿，要求加快第七项小球，并提出可使用 LottieFiles。1.61 实施普通/加强速度各增加 50%，以第七项规则 v2 独立记录；保留 v1 条件与旧成绩。运动采用实时合成图层，未接入预制 Lottie；第五项及倒计时减少逐帧布局/重复写入。具体实现选择与验证边界见 [动态训练优化](../MOTION-161.md)。50% 为本次实现选值，尚待手机体验反馈。

## 常见的旧信息冲突

| 旧说法 | 当前应如何理解 |
| --- | --- |
| “只有原六项训练” | 当前注册表有十六项；六个根 HTML 是兼容输入，不是完整产品目录 |
| “备份 v2”或“工具版备份 v3” | 当前完整导出 v4，导入兼容 v1–v4；不能把当前 v4 导入旧 App 当作支持承诺 |
| “星球乐园是首页入口” | 属于历史版；当前隐藏入口但保留存储与备份 |
| “回到 1.1.0 基线” | 是当时功能方向，不代表要把当前代码和版本号降为 1.1.0 |
| “研究候选中的六项还没开发” | 候选文档记录当时状态；当前 11–16 已实现，不能再次当作全新功能规划 |
| “执行旧 check_*.cjs 发布” | 当前统一用 `android-app/dev.py`；归档脚本只作历史参考 |
| “_hub 模板是安卓构建入口” | 当前模板在 `android-app/templates/app.html`，`_hub` 仅留档 |
