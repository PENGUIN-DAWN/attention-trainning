# 项目定位

## 使用者与目的

**用户确认，2026-10-21：**“目前给身边周围几个人包括自己，主要是自用，就是为了训练注意力而做的项目。”

因此，当前服务对象是作者自己和身边几位朋友。项目以注意力练习为目的，优先把现有训练做得清楚、可操作、可持续使用。这里的目的不代表已经证明训练能改善日常注意力。

没有确认使用者年龄、临床情况、固定训练频率或效果指标，不能自行补写为儿童产品、治疗工具或已验证干预。

## 使用路径

打开目录 → 选择项目 → 阅读规则或示例 → 设置条件 → 正式训练 → 核对结果 → 查看本地记录。部分项目另有教学、声道确认或分段自报，不应强行统一成同一种流程。

更新前先导出完整备份，再覆盖安装。不要先卸载或清除数据。包名、签名、WebView 来源和存储键共同构成升级兼容边界，见[数据与签名](../DATA-AND-SIGNING.md)。

## 产品边界

- 成绩表示具体任务和条件下的表现，不输出医学诊断、智商或综合注意力能力评分。
- 不同模式、规则版本、难度及相应显示条件的成绩分别比较；不能只凭用时排序。
- 呼吸练习是自报，不自动检测走神；返回次数多不表示能力更差。
- 双耳分听依赖用户确认左右声道，App 没有自动检测真实耳机。
- 研究文献支持探索某类任务，不等于本 App 的改编、剂量或迁移效果已经通过试验。
- 默认保留数据、旧安装包和离线能力；后续若改变这些边界，应明确记录用户决定及迁移方案。

以上边界来自[工程首页](../../README.md)、[1.40 发布说明](../../安卓手机版/更新说明-1.40.md)和[开发约定](../../CONTRIBUTING.md)。待决定的优先级见[待办](BACKLOG.md)。
