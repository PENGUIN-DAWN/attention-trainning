## 源码、签名与手机恢复

1. 源码用明确标签/提交恢复到隔离目录；没有提交的工作还需要工作区快照。Git bundle 不包含工作区和未跟踪文件，须同时保存并核对哈希。
2. 使用依赖锁安装开发工具，按 BUILD 配置 SDK/JDK、独立暂存和原签名目录，执行完整验证。没有原签名须停止，不生成新签名替代升级身份。
3. 签名私钥和配置独立加密备份，放在作者指定的受保护位置；公开仓库只记录证书指纹。当前文件存在与成功签署不等于独立备份恢复成功。
4. 手机先导出训练备份再覆盖安装；不卸载、不清除数据。普通源码回退不保证旧 App 能读取较新规则记录，因此从最新兼容代码修复功能并发布更高 versionCode。
5. 导入恢复先在隔离数据或备用设备验证；不把恢复演练直接作用于真实手机记录。更新后核对记录、设置、隐藏历史数据和重复导入。
