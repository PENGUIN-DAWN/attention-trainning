# 1.61 动态训练优化

2026-10-22，作者反馈第七项小球移动和其他动态项目有掉帧感，并要求提高小球速度，提出可使用 LottieFiles 素材。此反馈是实际使用体验；本次桌面检查不能确认具体安卓设备上的瓶颈。

## 实现与规则

- 第七项原来每帧重绘 600×600 Canvas，并写入倒计时。现在背景只绘制一次，小球使用 10/12 个复用图层及 `translate3d`；缓存节点与尺寸，渲染帧不读取布局、不绘制文字或画布。改变标记/编号只在阶段切换时进行。
- 物理计算保持反射边界和等半径碰撞，按固定 1/120 秒推进；显示帧插值相邻物理状态。模拟的 60/90/120 Hz 轨迹应得到相同最终物理位置，这不是声称手机运行于 120 FPS。
- 普通初始速度 0.16 → 0.24，加强 0.18 → 0.27（场地宽度/秒），均提高 50%。普通仍是 10 球、4 目标、标记 2.5 秒、运动 6 秒；加强仍是 12 球、5 目标、标记 2.5 秒、运动 8 秒；每轮 3 题。
- 第七项新训练为规则 v2。v1 校验保留原条件与速度；不迁移、重算或丢弃旧成绩。v1/v2 以及两个预设分别比较，备份仍是 v4，导入仍兼容 v1–v4。其他训练规则版本保持 1。
- 如果运动中相邻回调间隔超过 250 ms，中断该轮并明确提示；取消回调，只保留已有的中断记录，不算完成。避免一次性补算用户没有看到的大段轨迹。返回、切后台仍中断，不实现暂停续练。
- 第五项保留原网页和刺激变换，在安卓适配层将观察进度的逐帧宽度写入改为 `scaleX`；统计文字每 100 ms 检查一次，数值相同不写 DOM。观察计时仍在题面可见后开始，保持设置时长及重播行为。
- 第十一项仅在倒计时文本变化时写 DOM，不改变时钟、规则提示或作答期限。首页 SVG 仍采用 CSS 运动，增加合成提示，离屏、训练及后台停止装饰运动。

## Lottie 评估

查阅了 [LottieFiles](https://lottiefiles.com/) 和其 [输出格式说明](https://docs.lottiefiles.com/en/integrations/vscode/05_integrate/choosing-an-output-format)。现有动态图形是实时 Canvas、文字变换及简单 SVG/CSS，没有待替换的 GIF。

本次保留实时运动，没有引入 Lottie 播放器或第三方动画素材。随机目标、碰撞后的轨迹和停止位置参与答题，预制动画不能直接替代；简单缩放/旋转也已有原生合成路径。更换动画格式本身不能证明设备流畅度改善。未来需要独立装饰素材时可再按离线资源、许可和实测成本选型。

## 新源码契约

`ui-baseline-150.json` 原样保留。`motion-baseline-161.json` 记录四份明确变更的受保护源码及原哈希/新哈希/理由，另绑定新增运动脚本和样式。其余受保护文件继续使用旧哈希，包括原六项 HTML、旧 APK、训练 CSS、规则 11–16、音频时钟及存储。

共享工具页面的改动会嵌入 7–10，共享高级页面的倒计时改动会嵌入 11–16；并不表示修改了所有这些项目的规则。APK 核验分别检查旧原始模块、重新装配的共享模块、适配脚本、未变 CSS/音频和完整源码契约。报告明确标注引擎已不同于旧基线，不能继续输出“全部引擎一致”。

## 验证入口与限制

`python -X utf8 android-app/dev.py test --suite motion` 检查真实 v1 记录读写/导出/导入/条件分组、v2 与非法混合版本、8–10 预设生成器兼容、不同模拟刷新率的轨迹一致、普通与 4 倍 CPU 限速加强档、最终标签位置、运动中的停顿中断，以及第五项完整观察时长/后台取消。

性能检查独立于其他浏览器套件串行执行，原始结果见 `安卓手机版/动态训练验收-1.61.json`。对照页来自原 1.50 APK（其第七项与 1.60 同源）。帧间隔、布局次数、画布绘制次数和 CPU 时间都是指定 Windows 浏览器的软件测量；不等同安卓物理帧率。完整发布凭据、APK 静态结果分别查看同版报告。

尚需作者在实际手机比较第七项普通/加强、第五项放大/缩小/旋转、首页装饰、返回及后台，核对旧记录和备份，并记录机型、Android/WebView 版本与主观体验。

本次完整发布实际通过 64 组检查与 APK 静态核验。作者进一步描述小球有残影感后，另做了实时运动单帧核验：只有 10 个不透明小球图层，Canvas 只含均匀背景，未设置模糊、阴影或 CSS 过渡；截图已目视检查。补充 JSON/PNG 保存在同版交付目录，不计入完整运行的 64 组，不能据此断言手机残影已消失。
