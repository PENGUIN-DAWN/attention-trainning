# 1.63 第七项浅色、随机分布与流畅运动

2026-10-22，作者要求第七项小球颜色更浅、开始后随机均匀分布且逐颗出现、运动更流畅，以及仅在方框边缘增加自然轻微的光。此决定更新了 1.62“保持原球色”的要求；场地填色仍保持 `#f3f5fa`。

## 当前呈现

- 普通球为雾蓝 `#96b6ce`，确认目标为浅暖金 `#d2ae75`，保留固定高光与轻内阴影。运动前移除目标色与光圈，所有球保持相同外观；停止后的编号用深色提高可读性。
- 初始球心限制在场地 9%–91% 内；随机打乱四个区域的顺序，每个区域轮流加入一个点，用 48 个候选中与既有球距离最大的点保持分散，最后再次打乱身份与位置。十球每区 2–3 个、十二球每区 3 个，无固定行列；方向独立随机，初始速度仍为 0.24 / 0.27。
- 倒数、每 160ms 随机逐颗出现、入场短音与完整 2500ms 目标确认保留。十球正式运动仍 10000ms，十二球仍 8000ms；不挤占观察和作答时间。
- 方框伪元素只有透明内部、1px 描边和约 5px 衰减的低透明阴影，不填光、不脉动、不接收点击；原场地和圆角保留。

## 为什么不增加定时器次数

`requestAnimationFrame` 通常跟随显示刷新；额外跑更快的计时器不会让屏幕显示更多帧，反而可能增加主线程负担。依据：[MDN rAF](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)。`transform` 和 `opacity` 通常是适合动画的属性；实际是否在合成线程运行仍受浏览器和设备影响，见 [浏览器性能说明](https://web.dev/articles/animations-guide) 与 [Web Animations](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Using_the_Web_Animations_API)。

1.62 已用 rAF、120Hz 固定物理步长和位置插值，但每个显示帧仍逐球写入 DOM，离散碰撞还会修正位置。1.63 的规则 v4 在本题开始运动时，根据随机初始状态解析计算圆球/墙壁的精确碰撞时刻和弹性反射；碰撞前后位置连续。只在碰撞时刻和终点留下路径节点，沿直线匀速衔接，不用增加大量等距采样帧。

各小球用同一起点、相同总时长的原生 Web Animations `transform` 动画播放路径，浏览器按自己的显示节奏插值；正常运动期间不再每帧写每个球的样式。rAF 保留阶段时钟、低频倒计时文本与超过 250ms 停顿检测。结束时写入同一路径的准确终点后取消动画，再显示编号。缩放时更新关键帧而保留动画时间。后台、退出和长停顿都取消播放，不恢复已中断轮次。

API 缺失或启动动画失败时，使用同一条解析路径和 rAF 插值降级；不换成另一种运动，不跳过逐颗出现。减少动画仍只减少装饰入场和光圈脉动，必要的题目运动保留。没有承诺强制 120FPS，没有增加平台权限或网络依赖。

## 记录、契约与发布范围

球色、初始位置分布和运动模型都会影响训练条件，因此新成绩显式使用规则 v4（`appearance=soft-blue-sphere`、`placement=balanced-random`、`motionModel=continuous-collision`）。v1/v2/v3 的参数、旧生成逻辑、记录清洗和分组继续保留；四种规则、两档预设分成八组比较。备份仍为 v4，存储键、包名、签名及隐藏历史数据保留。

`motion-baseline-163.json` 追加绑定四份变更源码，1.50/1.61/1.62 契约原样保留。本轮沿用本对话已交付的 1.62 独立工作区，不覆盖主目录另一项尚未提交的公共反馈开发；该公共反馈工作并未合并进本安装包，音效沿用本对话 1.62 的已交付实现。

## 验证入口与边界

- `motion.cjs`：400 条带种子的路径、均衡分区、无固定行列、120Hz 采样的边界/不重叠、跨模拟刷新率轨迹、v1–v4 导入导出和八组比较；浏览器比较 1.62 与当前的位置样式写入及主线程任务时间，验证长停顿中断和终点编号。
- `tracking-quality.cjs`：320px 边缘微光与原背景、缩放后动画位置和解析路径一致、后台取消，以及无 Web Animations API 时完整运动/作答降级。
- `tracking-presentation.cjs`：真实分段时长、逐颗入场与非静音信号、浅色球、运动线索消除、静音和减少动画。

最终结果见同版运行凭据、APK 静态核验与[知识库证据](knowledge-base/EVIDENCE.md)。截图和无声视频是浏览器预览；安卓真机流畅度、屏幕拖影、实际刷新率、声音和覆盖安装仍需分别验证。
