# 1.60 浅蓝 UI 实现说明

2026-10-22，依据作者在 UI 专用对话提供的设计稿实施。版本 1.60 / code 9。用户要求保留悬停交互、增加灵动的动态效果，并把训练素材之外的图标统一为 SVG。

## 实现范围

- 奶油色背景、浅蓝操作色、白色圆角卡片；小屏双列、大屏多列目录。
- 首页 SVG 星球与云层、今日进度、最近使用、首页 / 足迹 / 说明底部导航。
- 鼠标悬停抬升、逐帧合并的指针微倾斜、箭头移动、按钮与卡片按压。
- 可见目录卡片分批入场；装饰星球只在首页可见区域活动，离开、后台或减少动画时停止。
- 页面进出沿用可取消的路由过渡，开始按钮等过渡完成后才启用。
- 弹窗支持入场与退出的透明度 / 位移过渡；旧 WebView 使用入场动画和原生关闭降级。
- 记录、空状态、删除确认、备份、示例、规则、设置和结果外框统一外观。
- 应用 UI 图标使用 `app/icons.js` 内联 SVG，插画由 `app/visuals.js` 生成。
- 安卓系统栏、窗口背景、启动与启动器图标同步；Android 原生资源采用 VectorDrawable，系统不直接接受 SVG Drawable。

## 明确保留的边界

未重写十六项训练规则、引擎、题量、计分、观察时长、音频、训练素材、颜色冲突或字号冲突。
不把设计稿中的逐题成功弹窗和暂停继续行为带入原训练。当前切后台仍中断，呼吸仍为自报。

根六项 HTML、`index.html`、`training.js/css`、tool / advanced 引擎与音频不改，1.50 题面基线继续逐项核对。
`chrome-ui.js` 经 `prepare_assets.py` 作为独立外围脚本注入，处理关闭图标、结果装饰和按钮箭头；不进入正式刺激区域。

包名、签名、WebView 来源、存储键与备份 v4 保留；旧 APK 不覆盖。第六项结果原“下一项”实际返回目录，现在显示“全部训练”，只修正按钮目的地文案。

## 工程入口

- 主题与主页：`styles/tokens.css`、`styles/shell.css`、`templates/app.html`。
- 训练外围：`styles/training-chrome.css`、`styles/dialog-motion.css`、`chrome-ui.js`。
- 交互：`app/motion.js`、`app/visuals.js`、`app/navigation.js`。
- 打包沿用 `dev.py`，`tooling/release.py` 同步本版说明和预览配色；未改变签名或发布校验门槛。
