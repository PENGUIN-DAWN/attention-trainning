## 结构化数据

原键不变：`focus-universe-history-v1`、`focus-universe-settings-v1`、`focus-universe-ui-v1`、隐藏的 `focus-universe-arcade-v1`、临时 `focus-universe-transaction-v1`。

新增稳定标识依次为 `rule-switching`、`breath-return`、`central-peripheral`、`go-no-go`、`dichotic-digits`、`serial-dual-target`。detail schema 3，ruleVersion 1，包含 params、results、status、device。每试次保存题目 q、答案 answer、responseMs、timeout、invalid、durations、maxGapMs；判分和汇总在校验时重新计算。

新数据不复用原 1–10 编号。呼吸 correct/errors 为 null，不参与最佳。完整且没有时序异常的轮次才参与同条件比较；视觉显示快照为开局父视口和 DPR，不使用会随内容改变的 iframe 高度。呼吸中断可保存未自报段的实际部分时长，答案为 null，不伪装成保持注意。

备份 envelope v4，导入兼容 1/2/3/4；只含旧字段的备份不会清空新增项目或娱乐数据。上限 24MB、训练合计最多 200 条；实际空间受 WebView 限制，失败保留原数据。导入先验证再事务提交。历史娱乐仅调用原规则/适配器读写备份，没有界面或奖励代码加载。

## 时序与音频边界

视觉序列在每个实际 rAF 边界切换，不按绝对时间追赶而跳过刺激；保存程序观察到的持续时间。长帧 >50ms 等会标记异常。此机制不能测量屏幕扫描/像素响应，不作为实验室硬件级定时保证。

Go/No-Go 的点击窗口按单调时钟严格限制在 1200ms 内，空白期仍有效；首次 pointerdown 之后忽略其他输入，呈现不随点击提前结束。每一试次都完整走完，不插入正误动画。

音频是离线 Microsoft Huihui 系统语音输出，九个数字同长度，单声道样本准备后在运行时写入一个双声道缓冲。只对用户主动操作启用 AudioContext，后台停止源并暂停上下文，异步解码也受代次取消保护。数字声道验证不等于实际耳机声道验证；系统单声道或硬件交换仍需人确认。

## 构建和检查

在项目根目录执行：

```
python -X utf8 android-app/build.py
python -X utf8 android-app/verify_release.py
python -X utf8 android-app/verify_digit_audio.py
python -X utf8 android-app/package_advanced_release.py
```

素材已内置，常规构建不运行语音合成，不联网。密钥沿用原脚本从工程外读取，不放入 APK、备份或交付 ZIP。

浏览器检查使用本机 Node、Playwright 和 Edge：

- `check_training_140.cjs`：原六项完整回归，真实时钟。
- `check_tools_140.cjs`：原 7–10 完整回归、倒序、数据兼容。
- `check_finish_140.cjs` / `check_tool_edges_140.cjs`：原完成页、数据和生命周期边界。
- `check_advanced_140.cjs`：2,000 组新规则生成、虚拟时钟正式整轮、真实音频时钟整轮、数字声道、备份与教学。
- `check_advanced_edges_140.cjs`：真实浏览器时钟、20s 呼吸、三种显示时长、12 字符、真实连续监测、掉帧、保存失败/后台重试、布局与音频中断等。保存边界使用 59 题有效夹具＋最后一道实际 UI 作答，不冒充另一次完整 60 题测试。

所有浏览器测试均使用隔离上下文和本地文件，不接触用户 App 存储。六份浏览器报告记录最终 HTML 的 SHA-256；打包脚本核对它们与 APK 内的页面一致。
