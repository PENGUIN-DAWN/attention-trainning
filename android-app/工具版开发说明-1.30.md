# 1.30 开发说明

本次产品基线是 1.1.0，安装版本是 1.30 / versionCode 5；不是安装降级。复用 1.2.0 的事务保护与备份数据适配，未加载 `arcade.js` / `arcade.css` / `shell.html`。旧娱乐文件仍在源工程中留存，数据原键不清除。

默认路由 `#home`；`#train/1` 到 `#train/10` 为十项训练。旧大厅/娱乐深链不会展示娱乐界面，会进入训练目录。

## 数据

原键继续使用 `focus-universe-history-v1`、`focus-universe-settings-v1`、`focus-universe-ui-v1`；娱乐键 `focus-universe-arcade-v1` 原样留存；事务键 `focus-universe-transaction-v1` 未改变。

新项目稳定编号 7/8/9/10，稳定 project 标识见 CONFIG。detail schema 2 / ruleVersion 1，params 保存完整条件，results 保存每题结果、作答毫秒、命中、错误、跳过、超时（字题包含字符对）。status 为 complete/interrupted；中断不参与今日完成或最佳。一轮全部作答后最后一题立即提交，查看结果不二次记分。按 token 去重，失败重试原 token。

舒尔特倒序仍是项目 1，mode reverse；结构化数据包含 direction descending / answerMode click / limitMs 35000 / colors 5 / ruleVersion 1。旧正序记录结构继续兼容，未补算旧字段。

备份 envelope version 3，兼容 1/2。最多 200 条、1,200,000 字节。旧备份缺 arcade 不写娱乐键；含 arcade 按原规则合并。新记录校验项目、固定条件、题数、结果范围和逻辑一致性。事务成功后再更新运行态。损坏的娱乐原文不自动清理，不能读取时导出会明确失败。

## 构建和验收

在项目根目录执行 `python -X utf8 android-app/build.py`，再执行 `python -X utf8 android-app/verify_release.py`。密钥由原脚本从项目外读取，不复制到源码、APK 或交付 ZIP。

本机 Node 在 `C:/Users/panhu/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`。

- `check_training_130.cjs`：原六项整轮、时间、记录、输入法事件、手机尺寸、导航、备份回归。
- `check_finish_130.cjs`：原完成页、30 秒边界、减少动画。
- `check_tools_130.cjs`：随机不变量、四项整轮、倒序、实际观察/运动、保存失败、备份、移动布局等。
- `check_tool_edges_130.cjs`：补充旧 v2 备份、事务、分组、阶段中断、移动与字体可读性检查。

浏览器使用隔离配置与本地文件，不读取手机真实数据。静态 APK 核验不等于 Android 真机验收。参数和安装方法见 `安卓手机版/更新说明-1.30.md`。
